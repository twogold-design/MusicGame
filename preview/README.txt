Godot 4.7.2 · 单场景 3D 解压小游戏

比赛包为 dist/MeowBeat-Web.zip。完整解压后根目录含 index.html。
用新版 Chrome 或 Edge 打开入口即可离线试玩。上传比赛时保留包内全部文件。
压缩包和解压后的文件总大小均小于 200 MB。

点击物件或卡通角色直接出手，也可用空格或 J 攻击高亮目标。
按住约 0.3 秒再松开会追加重击，约 0.75 秒蓄满。重锤能再次震飞碎片。
售货机散出汽水罐，街机可撞出连锁，柜子可能露出可砸的现金盒。
卡通角色被扇后各有不同的反应，名字会跟着角色显示。
战利品自动收取。点右上角「收工」结算。
ESC 暂停，Enter 开始或继续。切后台自动暂停，手机请横屏。
