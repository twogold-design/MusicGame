# 节拍冒险验收清单

本清单为待执行项，不代表功能已通过。实际测试需要记录构建版本、模式、曲目、地图种子和结果；旧四轨音游测试结果不得直接沿用。

## 第一眼和闭环

- [ ] 玩家能在 10 秒内说明目标：收集 → 回中央交付 → 修好三层 → 前往出口。
- [ ] 携带值与已存值分开显示，知道受伤会丢哪部分。
- [ ] 从开始、暂停、恢复、成功/失败到再来一局，流程完整。
- [ ] 修满 9 枚时不会直接结算；出口开放后到达才获胜。
- [ ] 尚未修复完成时提前走到出口不会获胜。
- [ ] 新一局重置生命、携带、已存、声部、能量、冲刺、时限、无敌和预告状态。

## 随机地图和物品

- [ ] 地图严格为 9 列 7 行，猫出生 `(4,6)`，唱机 `(4,3)`，出口 `(4,0)`。
- [ ] 多个固定种子验证三个关键位置可达，所有物品均位于可达可行走格。
- [ ] 障碍、物品与关键位置不会错误重叠。
- [ ] 物品耗尽、空间不足等情况下不会无限生成循环。
- [ ] 普通碎片加 1，金片加 2，容量不超过 5。
- [ ] 容量仅余 1 时拾值 2 金片只收 1，地面保留余值 1；容量满时物品保留原值。
- [ ] 受伤后重新出现或保留的物品仍可达，不重叠障碍。

## 拍点、方向与冲刺

- [ ] 普通每拍最多移动一格，按住按键或系统重复键事件不能刷步数。
- [ ] 方向键和 WASD 对应一致；上下左右不会越过地图边界。
- [ ] 提前输入会按设计缓存，不要求碰到某一渲染帧。
- [ ] 准确踩拍能加能量，反复空敲不能无限充能。
- [ ] 初始能量 2，上限 4，冲刺扣 2，能量不足不能免费冲刺。
- [ ] Shift 只准备下一次冲刺，不能在同一拍无限开启移动。
- [ ] 两格冲刺遇到第一格/第二格墙、地图边界时绝不穿墙，完全没移动不扣能量。
- [ ] 冲刺沿途逐格拾取，但只对最终落点判定危险；越过中间激光格不受伤，落到激光格会受伤。
- [ ] 冲刺路径与伤害在不同帧率下保持一致。
- [ ] 暂停、切后台、松键、触屏取消后不会残留移动或误触发冲刺。
- [ ] 低帧率或较长一帧不会多结算/漏结算节拍。

## 交付与音乐恢复

- [ ] 进入中央后把全部携带存入累计银行，不足 3 枚也接受；携带与银行数值守恒。
- [ ] 累计 3 / 6 / 9 解锁各一层，重复踏上中央不会重复解锁。
- [ ] 每修复一层恢复 1 心，并生成新高价唱片；同一次修复不重复发奖励。
- [ ] 初始只有鼓；三层按贝斯、和弦、主旋律顺序加入。
- [ ] 声部保持同一音频时钟，新加声部不跳拍、不从曲头重播。
- [ ] 扣心丢失随身物品，不回退已存数值和已修复声部。
- [ ] 修复完成后出口有明显可见变化，玩家知道下一目标。
- [ ] 静音、暂停、重来不会造成多组声部重叠播放。

## 激光、音箱与受击

- [ ] 激光每 4 拍攻击，首次与后续均有完整 4 拍预告。
- [ ] 前 8 拍无危险，前 32 拍仅单列扫描；之后才逐步引入行列组合与音箱。
- [ ] 中央唱机格永久安全，停留不会受到激光或音箱伤害，时间仍继续流逝。
- [ ] 预告格与实际攻击格相符，倒计时不提前归零或跳变。
- [ ] 伤害只在攻击拍发生，预告阶段不扣心。
- [ ] 后期音箱正确出现，移动和危险信息可提前读懂。
- [ ] 一次受击扣 1 心，丢失 `min(2, 当前携带)`。
- [ ] 受击后 2 拍内再次碰到激光或音箱不重复扣心。
- [ ] 同拍多种危险重合最多结算一次伤害。
- [ ] 无敌结束边界不会多保护或少保护一拍。
- [ ] 轻松 4 心、挑战 3 心；心归零立即进入一次失败结算。
- [ ] 预告与障碍组合不会形成无法脱身且没有可用策略的必伤局面。

## 时间、失败和成功

- [ ] 轻松 192 拍、挑战 160 拍；HUD 显示与真实剩余时间一致。
- [ ] 不同 BPM 都按拍计时，歌曲循环时地图拍号继续单调前进。
- [ ] 超时且未到开放出口时失败，不因已存满而错误获胜。
- [ ] 最后一拍到达开放出口的胜负顺序有明确且稳定的结果。
- [ ] 成功或失败只结算一次，之后输入不会改变得分、心数和进度。
- [ ] 结算能解释成功原因或失败原因，并提供直接重开。

## 输入、视听和网页交付

- [ ] 键盘、鼠标/触屏方向操作、冲刺与暂停均能完成一局。
- [ ] 触屏不会被模拟鼠标重复触发；不同方向的多指输入不会重复移动。
- [ ] 桌面与横屏手机下，地图、心、携带和拍数都完整可见。
- [ ] 障碍、危险预告、伤害区域、普通碎片、金片、中央与出口容易区分。
- [ ] 机关颜色之外还有形状、图案或文字倒数辅助判断。
- [ ] 激光和修复反馈不遮挡下一步危险位置，不使用刺眼全屏闪光。
- [ ] 本地 `index.html` 与静态托管均可玩，断网仍可完成全局。
- [ ] 新玩法构建已加入参赛 ZIP，入口位于根目录，压缩与解压均低于 200 MB。
- [ ] 测试、缓存、临时、构建文件全部留在 MusicGame 内。

## 趣味性检查

- [ ] 试玩过程中至少两次主动选择“回城保存”或“继续冒险”。
- [ ] 冲刺至少一次用于改变风险或路线，而不只是无脑按冷却。
- [ ] 第一次加回音乐声部时能明确听出自己改变了演奏。
- [ ] 机关预告让失败可解释：玩家知道自己哪一步贪心或走错。
- [ ] 换一个地图种子会改变路线选择，而不只是装饰位置。
- [ ] 一局结束后愿意尝试更少受伤、更快修复或更险的路线。
