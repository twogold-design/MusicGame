# 30秒节拍战斗原型

日期：2026-11-17。Godot 4.7.2，2D，默认进入战斗原型介绍页。范围是验证自由走位、准拍射击与冲刺的核心操作，暂未扩展长期关卡或养成。测试通过表示功能和流程成立，不代表替代玩家对手感与趣味性的评价。

## 核心规则

固定120 BPM；0–2秒四拍准备，2–32秒共60拍战斗，32–34秒收束。WASD自由移动，鼠标瞄准，左键逐拍点射；按住鼠标不自动开火。普通弹伤害2，冷却0.22秒；准拍重击伤害6、范围更宽且可穿透，正确踩拍可越过普通弹冷却，同一拍只能强化一次。

轻松5心、窗口±130ms；挑战4心、窗口±100ms。连续八个不同拍号的强化射击进入四拍三向狂热。拍外射击或漏拍断连。空格按当前移动方向冲刺，没有移动方向时朝准星冲刺，冷却1秒，短暂无敌；准拍冲刺可震碎半径140内的敌弹。

敌人首拍两只，前40拍逐拍补充，普通敌上限8，避开玩家170范围内直接出生；瞄准线提前一拍锁定，再按拍发射。第40拍音箱王入场，60HP，最后十秒可挑战击杀。第60拍结算，存活即可完成，击倒首领是进阶目标。触屏采用左侧摇杆和右侧点按射击/冲刺；触屏开火与J键辅助选择最近目标。

## 本轮调整

最初稀疏波次会让准拍击杀后出现多个空拍，因此提高出场密度并限制同屏上限。暂停期间拒收新的移动按下事件，恢复清除方向；冲刺读取当前按键而不是上一帧方向。保留弱弹操作即时响应，同时通过强化与狂热奖励稳定踩拍。
