# 节拍拆迁王原型

日期：2026-11-18。Godot 4.7.2、2D网页、30秒。当前默认玩法是破坏固定场景里的真实物件，替代此前的单线反击。目标是让破坏反馈承担节奏奖励，同时保持单键可玩。

## 当前规则

角色自动接近亮起的家具，空格/J/点按轻砸，按下后保持至少0.28秒再松开追加重砸，任何拍都能蓄力。点击具体家具可同时选中并砸，不是必做的第二步。无走位、瞄准找怪、危险弹幕或掉血失败。

120BPM，2秒准备、30秒破坏；12秒切办公室，22秒切街机厅。三间房共31件家具和墙面。拍外轻砸伤害0.55，准拍2.4；拍外重砸2.4，准拍5.8。连续四拍自动伤及相邻家具；重砸有更大连锁范围。提前输入缓存到鼓点，宽松前后150ms、精准前后110ms。失误不停止伴奏，也不终止游戏。

物件有实际HP、裂痕和死亡状态；砸碎后原贴图按网格分成碎块，带速度、重力、旋转、边界反弹、地面弹跳与静止状态。碎块落地后保留，清场后还能震飞残骸。被拆墙面留下暗洞，房间切换不销毁旧房间的破坏数据。物理为脚本简化模拟，不是完整刚体结构坍塌。

木板、玻璃、金属使用不同短破碎声，重拍叠加低音砸击。伴奏和响应旋律复用双同步音轨，碎片本身不逐个播放音效，避免堆叠遮鼓。
