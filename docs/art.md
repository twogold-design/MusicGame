# MEOW BEAT 美术素材

本项目所有 SVG 均为原创手工矢量绘制，不含外部链接、字体、脚本或嵌入位图。可离线加载，采用 SVG 原生渐变与图形，不需要网络依赖。

- `stage.svg`：1600 × 1000 夜间猫咪 DJ 舞台。推荐 `object-fit: cover`，视觉主体位于右侧偏中，保留空间层次。
- `cat-dj.svg`：480 × 480 透明背景猫咪 DJ，可独立做节拍缩放、摆动动画。
- `cover-sunset.svg`：落日汽水唱片封面，桃粉落日和海面。
- `cover-neon.svg`：霓虹夜行唱片封面，青色月亮和都市夜路。
- `cover-cosmic.svg`：星际派对唱片封面，粉紫行星和青色星环。
- `favicon.svg`：猫咪图标。

统一配色：墨蓝 `#101222`，酸橙 `#d8fa8b`，珊瑚粉 `#ef8fae`，青色 `#81d8d4`，紫色 `#9b88de`。所有插图无文字，可由页面提供可访问的中文标签。
