# 3D 商场验证

场景使用独立 World3D 和正交镜头。物件掉下的部件由 RigidBody3D 驱动，并与商场地面和墙面碰撞。最多保留 320 个物理碎片。场景提示和命中判定读取同一首混合音轨的播放时钟。前四拍是引子，之后循环 48 秒的主段，循环时拍号连续。每四小节可切换玩法段落，同一个时钟驱动接力、回弹以及爆破传播。

从工程根目录运行原生检查。以下环境变量把测试存档保存在工程中。

```powershell
. .\tools\environment.ps1
$env:APPDATA = Join-Path $projectRoot '.runtime\wreck3d-test-roaming'
& $godot --headless --path $projectRoot --script tools/test_wreck3d.gd
$env:APPDATA = Join-Path $projectRoot '.runtime\wreck3d-audio-test-roaming'
& $godot --headless --path $projectRoot --script tools/test_wreck3d_audio.gd
```

场景检查覆盖地面提示与拍点、准拍和拍外差异、蓄力松手、半拍连击、道具连锁、接力换位、角色回弹、低音箱的半拍冲击、循环补货、现金盒、碎片、角色名字、暂停、结算和重开。音频检查覆盖混合轨循环、连续拍号、打击音和暂停恢复。

构建并解压比赛包后，可按 README 的步骤运行网页检查。脚本验证仓库入口、解压后入口和 localhost，覆盖键鼠准拍、双拍连击、蓄力松手、触屏、暂停、收工、重开和竖屏提示。截图写入 `artifacts/`。
