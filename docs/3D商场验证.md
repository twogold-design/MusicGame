# 3D单场景商场验证

日期：2026-11-18。当前默认是真正Godot3D「午夜百货」，取代此前2D分房间版本。整局48秒固定同一个商场、同一镜头；空间中同时存在家具、保险柜、货架和三个卡通人物。物件选择、人物靠近及钱币收集自动完成，主操作仍是点砸与按住松开重砸。

## 实现范围

SubViewport拥有独立World3D，Camera3D渲染实体MeshInstance3D；没有把2D家具立绘摆成假3D。程序化模型覆盖十种家具、猫咪锤手及卡通人物。家具先掉局部零件，再拆成带BoxShape3D的RigidBody3D，用Godot物理处理重力、碰撞、翻滚与落地。碎片最多保留320块，使用碎片之间不互撞与静止休眠控制网页负担；这是拆件破坏，不是完整连续体断裂仿真。

货架、柜子和保险柜半血露出现金盒，现金盒不会再生现金盒。零钱沿弧线自动吸向主角，结算前结清尚在飞行的奖励。单场景大件保留足够耐久，世界从开始到终曲不切换，也不重置已经发生的破坏。

选中催加班经理、插队大叔或开会达人时，同一个操作改成扇巴掌，使用手掌、Head独立关节、身体摇晃/旋转和短脆slap音反馈，没有血腥表现。没有额外追逐、战斗或拾取任务。
