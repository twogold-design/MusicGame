# 节拍冒险验证

日期：2026-11-17。Godot 4.7.2，Windows Chrome，所有产物与测试资料存放在MusicGame目录。

## 完成的玩法

默认入口改为「节拍夺回行动」。9×7随机可达舞池，WASD/方向键按拍移动，输入可缓存，准确踩拍积攒冲刺。沿途收集普通旋律或金唱片，回中央累计交付3/6/9枚，实际解锁贝斯、和弦、旋律声部；最终从顶部撤离。激光提前4拍预告，音箱提前1拍标记，受击掉落随身旋律，中央安全。经典四轨模式保留独立入口。

## 修复

- 同一次交付跨越两个修复节点时，按实际声部数量增加奖励与生命。
- 激光攻击由拍数固定，不再随预告期间的修复状态突然改变；前32拍单列，第64拍后才出现组合扫射。
- WAV循环结束帧按采样率和乐句时长计算，兼容Godot导入后的压缩音频。
- 胜利结算保持完整合奏播放，游戏计时与操作结束；失败暂停音乐。
- 测试退出时等待音频线程回收，最终无ObjectDB未释放对象或脚本错误日志。
