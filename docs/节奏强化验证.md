# 节奏强化原型

日期：2026-11-18。Godot 4.7.2，2D，默认进入节拍战斗。当前仍是30秒核心玩法原型；自动验证只证明功能，不替代玩家对趣味与手感的判断。

## 玩法变化

120BPM，2秒准备，30秒战斗，2秒收束。共64个动作，51次射击、13次闪避。前八拍练习射击且不受伤，此后按“射、射、闪、射”循环，四个小节末尾加入半拍双击。WASD自由走位，鼠标瞄准，左键/J射击，空格闪避；触屏提供摇杆与射/闪按钮。

移除了拍外弱弹，输入须匹配动作和时间窗口。轻松提前150ms/延后140ms，挑战提前110ms/延后100ms。提前按下会缓存，在鼓点执行；晚按在窗口内立即执行。下方动作轨道提前显示乐句。瞬时穿透光束让命中与动作同帧。每8次连续正确动作获得4拍三向狂热。第三拍漏闪在延后窗口结束后扣血。

伴奏只提供鼓、贝斯与和弦。玩家正确操作才补出对应旋律/闪避短音。提前输入通过与伴奏同启动的双响应轨打开音量，音符时间写在波形里；晚按即时播放独立短音。两轨交替承载相邻动作，关闭窗口不会带出下一次未接住的旋律。

## 验证文件

- tools/test_groove.gd：真实场景的判定、缓冲、穿透、闪避、狂热、暂停与音轨生命周期验证，结果见 artifacts/groove-mechanics.txt。
- tools/test_groove_stems.gd：AudioEffectCapture录制实际混音输出，以伴奏起音为基准比较旋律起音，结果见 artifacts/groove-stem-gating-results.txt。旧动态play方案的抢拍实验保留为历史诊断。
- tools/groove_browser_check.cjs：实际键鼠输入完成64动作，检查首领、半拍、触屏、暂停、旧模式及离线请求，结果见 artifacts/groove-browser-results.json。
- tools/groove_platform_check.cjs：HTTP静态托管、900×450触屏、竖屏提示、暂停及重新解压ZIP后本地入口，结果见 artifacts/groove-platform-results.json。
