# 单线节拍反击原型

日期：2026-11-18。Godot 4.7.2、2D网页、30秒。此次针对“躲弹、瞄准找怪、跟节奏同时进行导致注意力过载”的反馈，把当前默认玩法替换为单线反击。

## 当前操作

猫咪固定在左侧，敌人按恒定430像素/秒从右侧靠近同一击打圈。敌人本身表示时机，没有独立音符轨道；没有自由走位、鼠标瞄准和危险弹幕。普通敌人到圈点一下，金色长敌的头部到圈按住，尾巴到圈松开。键盘空格/J、鼠标和触屏任选一种，点击位置不影响命中。

64个动作中56个普通点按、4个长按起点、4个松开。长敌在第13→14、29→30、45→46、57→58拍，末段43.5/47.5/51.5/55.5拍加入四次半拍点击。固定120BPM，2秒准备、30秒操作。长敌头尾用同一条金色连线呈现，半拍双击用邻近敌人预告，速度始终一致。

前八拍不受伤，轻松8心/前后150ms，挑战5心/前后110ms。提前操作缓存到鼓点执行，窗口内晚按立即执行；按下均有圈亮反馈。漏长敌头部会一并结束尾部，早松只扣一次，不重复扣血。失误后伴奏继续。局中只保留心数、连拍、进度与当前提示，详细分数和准确情况放到结算。首领自动受到反击命中，不需要选择目标。

## 实际验证

- tools/test_counter.gd：真实main.tscn实例，109项通过。覆盖完整64cue与音频metadata逐项对应、判定边界、提前/延后输入、长按早松/漏头单罚、重复输入、多输入源、半拍、暂停长按恢复、失败停止、重开清理，以及仅空格完成64动作并击倒首领。报告artifacts/counter-mechanics.txt。
- tools/test_counter_stems.gd：正式运行路径AudioEffectCapture录制，34项通过。tap、hold起点、release三个起音相对伴奏误差−0.726/−0.272/−0.499ms，平均绝对误差0.499ms。无双响、漏拍漏音，暂停恢复后音轨同相位。报告artifacts/counter-audio-results.txt。该数字是混音内部相对同步，不是实体设备端到端延迟。
- tools/counter_browser_check.cjs：通过真实空格输入完成64动作、四次重拳、64连拍、8心通关并击倒首领，得分8200；这是自动输入的流程验证。另检查长按中暂停/恢复、触屏点按与长按、HTTP静态托管、900×450横屏、竖屏提示、旧冒险入口及最终ZIP重新解压后的本地点击。报告artifacts/counter-browser-results.json。
- 已检查介绍页、长按、普通反击、结算与触屏截图。打飞的敌人向上离开来敌线，避免遮挡后续敌人。

## 交付与范围

dist/MeowBeat-Web.zip根含index.html，压缩和解压大小以dist/manifest.json为准，构建时分别强制小于200,000,000字节。源码、素材、缓存、临时文件、测试浏览器资料与导出均位于M:\NewGames\MusicGame。

验证环境为Windows Chrome、本地file与localhost HTTP、触屏模拟；未在实体手机、Safari或实际比赛平台验证。自动测试证明功能与流程成立，趣味性仍需玩家体验。本版先验证单一注意目标下的节奏手感，不扩展养成或长关卡。
