# MEOW BEAT 试玩验收清单

以下是待执行检查，不代表已经通过。实际执行结果由主代理记录在测试报告中。

## 交付与离线

- [ ] 在项目根目录直接打开 index.html 能进入首页。
- [ ] ZIP 完整解压到项目内的独立验收目录，根目录入口可直接打开。
- [ ] 禁用网络后进入任意曲目并完成一局，没有外部字体、音频、脚本请求。
- [ ] 运行包与 ZIP 均严格小于 200,000,000 字节。
- [ ] ZIP 不混入缓存、浏览器用户数据、测试依赖和截图。
- [ ] 工程、构建、缓存与测试输出均留在 MusicGame 目录内。

## 音乐和节奏

- [ ] 必须点击开始后才启动音频，兼容浏览器自动播放限制。
- [ ] 三首曲目均有可辨别的鼓、低音和旋律，不出现过载爆音。
- [ ] 倒数后第一个音符到线与可听节拍对齐。
- [ ] 音符接近曲尾时仍有音乐，最后一个音符判定结束才进入结算。
- [ ] 暂停后音频停止前进，恢复后时间和音符位置保持同步。
- [ ] 连续开始、重来、返回选曲，不出现多首音乐叠放。
- [ ] 静音和恢复音量正常，音量为零时不会阻止游戏计时。

## 判定和公平性

- [ ] 准时、轻微偏移、明显偏移分别出现对应判定。
- [ ] 同一输入只命中一个音符，keydown repeat 不重复判定。
- [ ] 空敲不加分、不能储存派对能量。
- [ ] 漏接只记录一次 MISS，并重置连击。
- [ ] 长按头命中、尾部完整保持有奖励，过早松开会断连。
- [ ] 长按尾部同轨不重叠新音符；同手双押在键盘与触屏上均可输入。
- [ ] 同谱面相同行为在不同帧率下得分一致。
- [ ] 全程不操作仍能结束，准确率为 0，不能得到全连。
- [ ] 派对奖励不使准确率超过 100%。

## 流程和状态

- [ ] 三首歌 × 两种难度均能开始、暂停、结束。
- [ ] 暂停时音符不被自动判漏，切换浏览器标签或窗口失焦有安全处理。
- [ ] 重开清空上一局分数、连击、判定统计、派对状态和输入按住状态。
- [ ] 暂停/返回/重开按钮快速点击不会触发重复计时器。
- [ ] 正常完成后只有一次结算；再挑战重新从开头开始。
- [ ] 每首每难度最好成绩独立存储，刷新可恢复。
- [ ] localStorage 不可用或数据损坏时仍可游玩。

## 可读性和操作

- [ ] 桌面 1366×768 下标题、按钮、轨道和判定线完整可见。
- [ ] 手机竖屏下四个按键可轻松点到，没有页面横向溢出。
- [ ] 手机横屏高度较小时，游戏区域和暂停按钮仍可访问。
- [ ] 触屏双指同时按下与长按不会触发浏览器滚动或缩放。
- [ ] 颜色之外还有固定位置和 D/F/J/K 文字区分轨道。
- [ ] 派对和连击提示不遮住接近判定线的音符。
- [ ] 暂停、设置、返回等按钮有明确可见文字与可点击范围。

## 趣味性现场试玩

- [ ] 首次玩家在十秒内找到开始按钮。
- [ ] 第一首前八拍能学会基本操作，随后看到明显变化。
- [ ] 至少触发一次派对，感觉到视觉和音乐共同升级。
- [ ] 失误后仍愿意继续打完，不会被惩罚反馈打断兴致。
- [ ] 曲末结算清晰说明表现，并能立即再来一局。
- [ ] 三首歌听感与谱面具有差异，普通难度不是单纯增加随机音符。
